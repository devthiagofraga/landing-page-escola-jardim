# 🌿 Escola Jardim - Landing Page Promocional & Agendamento

Landing page focada na captação de novos alunos para o período de matrículas da Escola Jardim, contendo validação de formulário em tempo real e interface responsiva e acolhedora.

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico:** Estruturação otimizada para SEO e acessibilidade.
* **CSS3 Moderno:** Paleta de cores personalizada, Flexbox, CSS Grid e componentes modais.
* **JavaScript (ES6+):** Validação de inputs (Nome, E-mail com Expressão Regular / Regex e Telefone) e controle de estado do modal.

## 💡 Recursos
* Validação no lado do cliente prevenindo envio de dados incorretos.
* Feedback visual dinâmico com mensagens de erro.
* Pop-up Modal de confirmação do agendamento.
* Layout responsivo otimizado para celulares e computadores.
